# IT Platform — frontend

Frontend платформы управления IT-инфраструктурой медицинской организации.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте `http://localhost:3000`.

## Демонстрационный вход

Логины: `admin`, `ithead`, `engineer`, `executive`, `user`. Пароль для всех: `demo`.

Авторизация и данные на первом этапе локальные. Компоненты подготовлены так, чтобы mock-функции можно было заменить вызовами backend API.

На компьютере без системного Node.js можно открыть готовую сборку двойным щелчком по `Открыть сайт.cmd`. Окно сервера должно оставаться запущенным во время просмотра.

JSON-конфигурации не поддерживают комментарии, поэтому сведения об авторе и назначении для `package.json` и `tsconfig*.json` зафиксированы в этом README.

## Готово в сеансе F01

- React + TypeScript + Vite;
- общая тема Ant Design;
- маршруты всех разделов;
- защищённая область приложения;
- Zustand-хранилище mock-авторизации;
- динамическое меню по ролям;
- страница входа и стартовый дашборд;
- адаптивный layout.
